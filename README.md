# เสื่อกกจันทบูร

เว็บไซต์หน้าเดียวแนะนำหัตถกรรมการผลิตเสื่อกกจันทบูร จังหวัดจันทบุรี สำหรับนักเรียน นักท่องเที่ยว และคนทั่วไป ออกแบบแบบ mobile-first (มือถือ → iPad → เดสก์ท็อป) ตามระบบดีไซน์ใน `DESIGN-kokchan.md`

HTML + CSS + JavaScript ล้วน ไม่ใช้ framework และไม่ต้อง build

## โครงสร้าง

```
index.html        หน้าเว็บ (๙ ส่วน: Hero → ประวัติ → ที่ตั้ง → ลาย → ขั้นตอน → ชุมชน → คุณค่า → อ้างอิง → Footer)
css/style.css     token และ component ตาม DESIGN-kokchan.md
js/main.js        เมนู, แถบความคืบหน้า, ไทม์ไลน์, แกลเลอรี, แผนที่, Lightbox
manifest.json     Web App Manifest
icons/            favicon และไอคอนแอป
images/           ภาพจริงจากแหล่งอ้างอิง (WebP)
```

## เปิดดูในเครื่อง

```
python -m http.server 8000
```

แล้วเปิด http://localhost:8000

เมื่อ deploy ให้เปลี่ยน `og:image` ใน `index.html` เป็น URL เต็มของโดเมนจริง และเปิด gzip/brotli กับ cache ที่เซิร์ฟเวอร์

## แหล่งข้อมูลหลัก

1. หอสมุดแห่งชาติรัชมังคลาภิเษก จันทบุรี กรมศิลปากร — จาก "เสื่อสมเด็จฯ" สู่ "เสื่อจันทบูร" https://www.finearts.go.th/chantaburilibrary/view/45574
2. A World Connect — เสื่อกกจันทบูร http://aworldconnect.com/index.php/region/356-kokchan
3. ฐานข้อมูลมรดกภูมิปัญญาทางวัฒนธรรม กรมส่งเสริมวัฒนธรรม https://ich-thailand.org/heritage/detail/675bbdc86bbf025285b1b30a

แหล่งข้อมูลเพิ่มเติม [4]–[15] (ทะเบียน GI ชื่อลาย และที่ตั้งชุมชน) อยู่ในส่วน "แหล่งอ้างอิง" ของหน้าเว็บ

## ลิขสิทธิ์และเครดิตภาพ

ลิขสิทธิ์เนื้อหาและภาพเป็นของหน่วยงานต้นทาง เว็บไซต์นี้จัดทำเพื่อการเรียนรู้ หากจะนำภาพไปใช้ต่อ โปรดขออนุญาตจากต้นทาง

| ไฟล์ใน `images/` | ต้นทาง |
|---|---|
| `fa-*`, `hero*`, `og.jpg` | หอสมุดแห่งชาติรัชมังคลาภิเษก จันทบุรี กรมศิลปากร [1] (ภาพสินค้าได้รับความอนุเคราะห์จากเพจร้านกอกกตามที่ต้นทางระบุ) |
| `awc-*` | A World Connect [2] |
| `ich-*` | ฐานข้อมูลมรดกภูมิปัญญาทางวัฒนธรรม กรมส่งเสริมวัฒนธรรม [3] |
| `mph2-*` | แบบ มภ.๒ เสื่อกกจันทบูร สำนักงานวัฒนธรรมจังหวัดจันทบุรี [7] |
| `jppj-*` | วารสารชัยพฤกษภิรมย์ (สมปอง มูลมณี และคณะ, 2565) [8] |
| `commons-chanthaburi-cathedral*` | Narongchaiv / Wikimedia Commons, CC BY-SA 4.0 — https://commons.wikimedia.org/wiki/File:NarongchaiV_0007075.jpg |

ทุกภาพแสดงตามต้นฉบับ ไม่ปรับสีหรือใส่ฟิลเตอร์ (ยกเว้นชั้นสีทับภาพ Hero เพื่อให้อ่านตัวอักษรได้)
